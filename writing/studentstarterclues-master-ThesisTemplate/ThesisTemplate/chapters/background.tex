\chapter{Background}
\label{ch:background}

\begin{itemize}
    \item Molecular dynamics
    \begin{itemize}
        \item Particle systems and time integration.
        \item Pairwise force computation.
        \item Lennard-Jones potential.
        \item Cutoff radius and short-range interactions.
    \end{itemize}

    \item Verlet lists
    \begin{itemize}
        \item Motivation for neighbor lists.
        \item Verlet radius as cutoff plus skin.
        \item Rebuild frequency.
        \item Force traversal between rebuilds.
        \item Tradeoff between rebuild cost and larger neighbor lists.
    \end{itemize}

    \item Linked cells and neighbor search
    \begin{itemize}
        \item Domain decomposition into cells.
        \item Candidate neighbor search through nearby cells.
        \item Relationship between linked cells and Verlet-list construction.
    \end{itemize}

    \item AutoPas concepts needed for this thesis
    \begin{itemize}
        \item Containers.
        \item Traversals.
        \item Functors.
        \item Data layouts.
        \item Only enough detail to understand the modified Verlet-list path.
    \end{itemize}

    \item Data layouts
    \begin{itemize}
        \item Array of Structures
        \begin{itemize}
            \item Particle object stores all attributes together.
            \item Pointer-based neighbor lists.
            \item Irregular pointer accesses during force traversal.
        \end{itemize}
        \item Structure of Arrays
        \begin{itemize}
            \item Separate arrays per particle attribute.
            \item Particle represented by common array index.
            \item Better suited for vectorized force kernels.
            \item Sorted SoA order can make traversal follow spatial particle order.
        \end{itemize}
    \end{itemize}

    \item Cache locality
    \begin{itemize}
        \item Cache hierarchy.
        \item Cache lines.
        \item Spatial locality.
        \item Temporal locality.
        \item L1D, L2, and shared L3.
        \item Cache misses and memory stalls.
        \item Why locality is measured indirectly through hardware counters.
    \end{itemize}

    \item Spatial ordering
    \begin{itemize}
        \item Linear order
        \begin{itemize}
            \item Simple coordinate linearization.
            \item Low encoding overhead.
        \end{itemize}
        \item Morton order
        \begin{itemize}
            \item Bit interleaving.
            \item Z-order curve.
            \item Better multidimensional locality than linear order in many cases.
        \end{itemize}
        \item Hilbert order
        \begin{itemize}
            \item Space-filling curve with stronger locality properties.
            \item Higher encoding cost.
        \end{itemize}
        \item Expected tradeoff between locality quality and encoding overhead.
    \end{itemize}
\end{itemize}
