\chapter{Conclusion}
\label{ch:conclusion}

\begin{itemize}
    \item Summary
    \begin{itemize}
        \item Global sorting for \texttt{VerletListsReferences} was implemented.
        \item Nine spatial sorting variants were evaluated.
        \item Sorted SoA traversal and neighbor-list sorting were added to make order visible to traversal.
        \item Correctness was validated against reference calculations.
        \item Benchmarks quantified runtime, overhead, and locality proxies.
    \end{itemize}

    \item Final answer
    \begin{itemize}
        \item State whether sorting improved locality.
        \item State whether sorting improved runtime.
        \item State which variant is most promising.
        \item State where overhead prevented gains.
    \end{itemize}

    \item Future work
    \begin{itemize}
        \item Cached sorting keys.
        \item Radix sort for integer keys.
        \item Faster Hilbert encoding.
        \item Parallel sorting.
        \item LIKWID marker instrumentation for force traversal and sorting phases.
        \item Autotuning sorting resolution/order.
        \item Further investigation of multi-threaded behavior.
        \item Newton3 support and interaction with sorted traversal.
    \end{itemize}
\end{itemize}
